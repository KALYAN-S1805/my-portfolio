# Kalyan S — Portfolio

A responsive, single-page portfolio inspired by the dark, minimal style of the reference portfolio video.

## Preview locally
1. Download and extract `kalyan_portfolio.zip`.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Before publishing
- Confirm that your GitHub username and LinkedIn URL are correct.
- Replace the project links with links to each actual repository.
- Add your email/contact details if you want them displayed.
- Add your own photo by replacing the initials card if you prefer.
- Check internship dates and certificate names for accuracy.

## Publish free with GitHub Pages
1. Create a repository named `kalyan-s1805.github.io` (or use any repository).
2. Upload `index.html`.
3. For a repository named `kalyan-s1805.github.io`, enable GitHub Pages in Settings → Pages and select the main branch.
4. Wait for GitHub Pages to publish the site.
